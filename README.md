# User Details

A Spring Boot REST API for managing user details.

## Tech Stack

- Java 21
- Spring Boot 4 (Spring Web MVC, Spring Data JPA, Validation)
- PostgreSQL
- Lombok
- Maven

## Getting Started

```bash
./mvnw spring-boot:run
```

Make sure a PostgreSQL database is running and configured in `src/main/resources/application.properties` before starting the app.
